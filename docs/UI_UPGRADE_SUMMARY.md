## 🎨 配色方案

### 主色调
- **Primary（主色）**: `hsl(199 89% 48%)` - 科技金融蓝
- **Success（成功）**: `hsl(142 76% 36%)` - 牛市绿
- **Warning（警告）**: `hsl(38 92% 50%)` - 活力橙
- **Destructive（危险）**: `hsl(0 84.2% 60.2%)` - 熊市红

### 浅色主题
- **背景色**: 纯白 `hsl(0 0% 100%)`
- **前景色**: 深灰 `hsl(240 10% 3.9%)`
- **卡片背景**: 纯白带透明边框
- **次要背景**: 极浅灰 `hsl(240 4.8% 95.9%)`

### 深色主题
- **背景色**: 深黑 `hsl(240 10% 3.9%)`
- **前景色**: 近白 `hsl(0 0% 98%)`
- **卡片背景**: 深灰 `hsl(240 10% 7%)`
- **次要背景**: 中灰 `hsl(240 3.7% 15.9%)`

## 🚀 特色功能

### Glass Morphism（毛玻璃效果）
```css
.glass {
  background: var(--color-background)/80;
  backdrop-blur: 12px;
  border: 1px solid var(--color-border)/50;
}
```

### 渐变背景
- `gradient-primary`: 主色渐变（蓝色系）
- `gradient-success`: 成功渐变（绿色系）
- `gradient-warning`: 警告渐变（橙色系）
- `gradient-danger`: 危险渐变（红色系）

### 自定义动画
- **pulse-glow**: 发光脉冲动画（用于状态指示器）
- **shimmer**: 闪烁动画（用于加载状态）
- **card-hover**: 卡片悬停效果（阴影 + 抬升）

- 移动端：底部导航栏 + 简化布局

## 🔧 使用指南

### 主题切换
用户可以通过顶部导航栏的主题切换按钮在三种模式间切换：
- 🌞 浅色模式
- 🖥️ 跟随系统
- 🌙 深色模式

### 自定义颜色
如需调整配色，修改 `app/globals.css` 中的 CSS 变量：
```css
@theme {
  --color-primary: hsl(199 89% 48%); /* 修改主色调 */
  /* ... 其他颜色变量 */
}
```

### 添加新的渐变
在 `globals.css` 中添加新的渐变类：
```css
.gradient-custom {
  background: linear-gradient(135deg, color1, color2);
}
```
